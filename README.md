Calculating Distance Between Two Points Using Math and I/O Libraries

Description
- My program helps calculate the distance between two points using the Math library.

How to Run
- Open the program.
- Run the program.
- Use sqrt() and pow() from the Math library
- Input the two points (x1, y1) and (x2, y2)

Input Needed
- Enter x1: 2
- Enter y1: 3
- Enter x2: 7
- Enter y2: 8

Sample Output
   
    Enter coordinate: X2
    Enter coordinate: Y3
    Enter coordinate: X7
    Enter coordinate: Y8
    The Distance between the coordinate is, 7.07
